Research and industrial experiences that complemented my academic training.

Mar 2026 – Present

Thesis Internship (Full-Time) · SunCubes · Milan, Italy

Working on drone pose estimation for autonomous navigation and sensing applications. Designing and implementing a Multiplicative Extended Kalman Filter (MEKF) for drone attitude and pose estimation. Developing the estimation framework in Python using PyMAVLink, PX4 simulation, and QGroundControl. Testing and validating the filter using both PX4 simulation data and real experimental drone measurement data. Developing sensor-fusion algorithms using IMU, GPS, and barometer. Investigating robustification techniques to improve MEKF reliability under noisy measurements, disturbances, and sensor uncertainty. Implementing a Federated Kalman Filter architecture to fuse laser-based measurements with the MEKF pose-estimation pipeline.
