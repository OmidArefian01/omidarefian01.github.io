Optimal Control and Trajectory Generation with NLP and PMP

A nonlinear optimal control problem for a simplified 2D vehicle: drive the system from an initial state to a target while minimising control effort, avoiding an obstacle region, and comparing solution strategies — indirect single shooting via Pontryagin's Minimum Principle, direct single shooting, and LQR tracking around the nominal trajectory.

Problem Statement

Project Assignment

Vehicle Dynamics

The vehicle is modelled as a point mass moving in the \(xy\)-plane with state \(\mathbf{z} = [x,\, y,\, v,\, \varphi]^\top\) and controls \(\mathbf{u} = [u_1,\, u_2]^\top\):

\[ \dot{x} = v\cos\varphi, \qquad \dot{y} = v\sin\varphi \] \[ \dot{v} = \frac{1}{m}\bigl(u_1 - C_d\,v^2\bigr), \qquad \dot{\varphi} = u_2 \]
ℹ

\(u_1\) is the thrust input; \(u_2\) is the angular rate input that directly changes the heading angle \(\varphi\). Drag is modelled with a quadratic velocity term \(C_d v^2\).

Cost Function

The objective \(J\) combines a terminal accuracy penalty, a running control-effort cost, a cubic velocity term, and a smooth obstacle penalty \(\Pi(x,y)\):

\[ J = \tfrac{1}{2}\bigl(\mathbf{z}(t_f) - \mathbf{z}_f\bigr)^\top P\,\bigl(\mathbf{z}(t_f) - \mathbf{z}_f\bigr) \] \[ + \int_0^{t_f}\Bigl[\tfrac{1}{2}w_1 u_1^2 + \tfrac{1}{2}w_2 u_2^2 + \beta v^3 + \Pi(x,y)\Bigr]\,dt \]
ℹ

The terminal weight matrix \(P\) penalises final position and velocity errors. The running cost trades off control effort against path straightness and obstacle proximity.

Modelling

Assumptions & Model Setup

Modelling Assumptions

  • The vehicle is modelled as a point mass moving in a 2D plane.
  • The thrust input \(u_1\) directly affects the longitudinal acceleration.
  • The angular control input \(u_2\) directly changes the heading angle.
  • Aerodynamic drag is modelled with a quadratic velocity term \(C_d v^2\).
  • The obstacle is represented by a smooth Gaussian penalty rather than a hard state constraint, ensuring differentiability.
  • The simplified dynamics neglect rotational inertia and higher-order actuator dynamics.

Obstacle Penalty

The obstacle is placed at centre \((x_c, y_c)\) with effective radius \(r\) and spread \(\sigma\). The penalty grows exponentially as the vehicle approaches the forbidden region:

\[ \Pi(x,y) = \alpha \exp\!\left(\frac{r^2 - (x-x_c)^2 - (y-y_c)^2}{\sigma}\right) \]

Solution Strategies

Methods Compared

Three solution strategies are compared: the indirect method based on Pontryagin's Minimum Principle, direct single shooting, and LQR tracking around the nominal trajectory.

Indirect Method

Single Shooting with PMP

Optimality conditions are derived analytically from the Hamiltonian. The state is integrated forward, the costate backward, and controls are updated from the stationarity condition \(\partial H / \partial \mathbf{u} = 0\):

\[ \mathcal{H}(\mathbf{z},\mathbf{u},\boldsymbol{\lambda}) = \ell(\mathbf{z},\mathbf{u}) + \boldsymbol{\lambda}^\top f(\mathbf{z},\mathbf{u}) \] \[ \dot{\boldsymbol{\lambda}} = -\frac{\partial \mathcal{H}}{\partial \mathbf{z}} \] \[ \boldsymbol{\lambda}(t_f) = \frac{\partial \phi}{\partial \mathbf{z}}\bigg|_{t_f} = P\,\bigl(\mathbf{z}(t_f)-\mathbf{z}_f\bigr) \] \[ \frac{\partial \mathcal{H}}{\partial \mathbf{u}} = \mathbf{0} \]
Direct Method

Direct Single Shooting

The control sequence is treated as the decision variable. State evolution is computed by forward simulation and the cost gradient is evaluated numerically. The optimisation is performed directly over the control parameters:

\[ \mathbf{z}_{\mathrm{dec}} = \bigl[u_{1,1},\ldots,u_{1,N},\; u_{2,1},\ldots,u_{2,N}\bigr] \] \[ \mathbf{z}_{k+1} = \mathbf{z}_k + \Delta t\, f(\mathbf{z}_k,\mathbf{u}_k) \]
ℹ

No adjoint equations are required. The gradient \(\nabla_{\mathbf{u}} J\) is computed by finite differences or automatic differentiation.

LQR Tracking

Linearisation Around Nominal Trajectory

The system is linearised around the optimal trajectory \(\mathbf{z}^*(t),\,\mathbf{u}^*(t)\) and a time-varying LQR gain is computed by solving the Riccati equation backward in time:

\[ \delta\mathbf{z} = \mathbf{z} - \mathbf{z}^*(t), \quad \delta\mathbf{u} = \mathbf{u} - \mathbf{u}^*(t) \] \[ \delta\dot{\mathbf{z}} = A(t)\,\delta\mathbf{z} + B(t)\,\delta\mathbf{u} \] \[ -\dot{P} = A^\top P + P A - P B R^{-1} B^\top P + Q \] \[ K(t) = R^{-1} B(t)^\top P(t) \]

Algorithm

Implementation Logic

Step-by-step description of the indirect solution numerical procedure.

Indirect Solver Workflow

  • Initialise control profiles \(\mathbf{u}^{(0)}(t)\) (e.g., zero or random).
  • Integrate the nonlinear state equations forward in time from \(\mathbf{z}(0) = \mathbf{z}_0\).
  • Compute the terminal costate from the terminal penalty: \(\boldsymbol{\lambda}(t_f) = P(\mathbf{z}(t_f) - \mathbf{z}_f)\).
  • Integrate the adjoint (costate) equations backward in time from \(t_f\) to \(0\).
  • Evaluate the Hamiltonian stationarity gradient \(\partial \mathcal{H}/\partial \mathbf{u}\).
  • Update controls using gradient descent: \(\mathbf{u} \leftarrow \mathbf{u} - \eta\,\nabla_\mathbf{u}\mathcal{H}\).
  • Repeat until the optimality residual \(\|\nabla_\mathbf{u}\mathcal{H}\|\) is sufficiently small.

Key Numerical Choices

The state and costate equations are integrated using a fixed-step Runge-Kutta scheme. The gradient step size \(\eta\) is chosen small enough to ensure convergence but large enough to make progress in a reasonable number of iterations.

The obstacle penalty \(\Pi(x,y)\) contributes to both the Hamiltonian running cost and, through the adjoint equations, to the costate derivatives. Its smooth exponential form ensures the gradient information is well-defined everywhere, including close to the obstacle boundary.

ℹ

Convergence is declared when \(\|\nabla_\mathbf{u}\mathcal{H}\|_\infty \leq \varepsilon_{\mathrm{tol}}\). The LQR gain is computed as a post-processing step on the converged nominal trajectory.

Analysis

Discussion

Interpretation of the results and the significance of the method comparison.

What the Results Show

The optimised trajectory avoids the high-penalty area around the obstacle while still reaching the desired target within the specified terminal accuracy. The comparison demonstrates that both the indirect and direct approaches are valid and produce consistent results, although they differ in sensitivity to initialisation, computational effort, and the shape of the final path.

The smooth Gaussian obstacle penalty proves effective: it guides the optimiser away from the forbidden region without requiring constraint-handling machinery, and its gradient information propagates cleanly through the adjoint equations.

Why It Matters

This project directly connects optimal control theory to a concrete motion-planning problem. It demonstrates how the trade-off between control effort, terminal accuracy, and obstacle avoidance can be embedded inside a single scalar cost function, avoiding the need for separate constraint solvers or penalisation heuristics.
